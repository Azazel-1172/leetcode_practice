把 LeetCode 題目的解法程式碼去掉**所有註解**，另存成乾淨副本。目標題目：$1（若為空，取 `daily/` 底下日期最新的那一題）。

## 步驟

1. 用 `ls daily/` 找到目標資料夾，列出裡面所有 `solution.*` 檔（目前有 `.ts`、`.js`、`.cpp`，未來多出來的同名副檔也一律處理）。
2. 逐一讀取每個 `solution.<ext>`，依「過濾規則」去掉註解。
3. 把結果用 Write 寫到**同資料夾**的 `solution.clean.<ext>`（原始 `solution.<ext>` 保持不動，不要覆蓋）。
   若 `solution.clean.<ext>` 已存在就直接覆蓋更新。
4. 回報處理了哪一題、產生了哪幾個乾淨檔，一到兩行就好。

## 過濾規則

這些檔都是 C 系列語法（`.ts` / `.js` / `.cpp`），註解只有兩種：

- **行內註解** `// ...` ：整段（含前面的空白）到行尾都刪掉。
  - 若一行只有註解，整行刪掉。
  - 若是**尾隨註解**（程式碼後面接 `//`），只刪掉 `//` 起的部分，並把它前面多餘的尾端空白一起清掉；程式碼本身保留。
- **區塊註解** `/* ... */`（含 JSDoc 的 `/** ... */`）：整段刪掉，跨多行也一樣。
  - 檔案最上面那段題目資訊（題號 / 題名 / LeetCode 連結 / 難度）也是註解，**一起刪掉**，不要保留。

**收尾**：

- 註解刪掉後留下的空白行，若造成連續兩個以上的空行，壓成最多一個空行；不要留一堆空行。
- 檔案開頭若因為刪掉標題註解而多出空行，把開頭的空行清掉，讓程式碼從第一行開始。
- 檔案結尾保留一個換行符即可。
- 程式碼的縮排、內容、邏輯一個字都不能動，只動註解與空行。

## 不要誤刪

- 字串或字元字面值裡面的 `//` 或 `/*`（例如字串常數 `"http://..."`、`'//'`）**不是註解**，不能刪。
  這些題的解法通常沒有這種字面值，但仍要檢查過再動手。
- 不要把註解的中文內容「翻譯」或「改寫」——是刪掉，不是搬移。
