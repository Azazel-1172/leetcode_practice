# 手機推播設定

`.github/workflows/daily.yml` 每天台灣時間 08:05 會自動做這些事，不用開電腦：

1. 抓今日挑戰（leetcode.cn 官方翻譯，免費），把題目資料夾 commit 到 `main`
2. 把總覽 app 輸出成唯讀網站，部署到 GitHub Pages（手機可安裝成 App）
3. 推播到手機，點開直接看到當天的題目

本機寫題前先 `git pull`，題目就在 `daily/` 裡了。想照舊開分支，就再跑一次
`python3 lcdaily.py fetch`：它會開 `daily/...` 分支，已經存在的檔案都不會被覆蓋。
筆記、解答合併回 `main` 之後，網站會自動重建，手機上也看得到。

## 一次性設定

### 1. 開啟 GitHub Pages

repo → **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

> 公開 repo 的 Pages 網站也是公開的，筆記內容任何人都看得到。

### 2. 設定推播（擇一或都設）

到 repo → **Settings → Secrets and variables → Actions → New repository secret**。

**ntfy（推薦）**

1. 手機安裝 [ntfy](https://play.google.com/store/apps/details?id=io.heckel.ntfy)
2. App 裡按「+」訂閱一個 topic，名稱自己取、**要難猜**（例如 `lc-daily-8f3k2q`）——
   topic 名稱就是密碼，知道的人都能看到推播
3. 新增 secret：`NTFY_TOPIC` = 剛剛的 topic 名稱

**Discord**

1. 頻道設定 → **整合 → Webhook → 新 Webhook**，複製 Webhook 網址
2. 新增 secret：`DISCORD_WEBHOOK_URL` = 那個網址

兩個都沒設的話，流程照跑，只是不推播。

### 3. 第一次手動跑

repo → **Actions → 每日挑戰 → Run workflow**。跑完後：

- 手機收到推播，點開進到當天的題目
- 在 Chrome 開網站 → 右上選單 →「**安裝應用程式**」，之後從主畫面開就像 App，
  沒網路時也能看開過的題目

## 疑難排解

**題目變成英文**：GitHub 的機器被 leetcode.cn 的 Cloudflare 擋了（log 會出現
「leetcode.cn 被 Cloudflare 擋住」）。題目還是會 commit、推播，只是沒有中文。
在本機跑 `python3 lcdaily.py fetch --no-branch --force` 換成官方翻譯再 push 即可。

**本機測試推播**：

```bash
NTFY_TOPIC=你的topic python3 lcdaily.py notify --site-url https://<帳號>.github.io/leetcode_practice/
```

**本機預覽手機版網站**：

```bash
python3 lcdaily.py build-site --out _site
python3 -m http.server -d _site 8000   # 開 http://127.0.0.1:8000
```
