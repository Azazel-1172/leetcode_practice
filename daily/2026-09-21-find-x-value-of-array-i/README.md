# 3524. 求陣列的 X 值 I

> 英文原題：Find X Value of Array I

> 翻譯來源：Claude Code

## 題目

給你一個由**正整數**組成的陣列 `nums`，以及一個**正整數** `k`。

你可以對 `nums` 執行**一次**操作：在這次操作中，你可以從 `nums` 移除任意**不重疊**的前綴（prefix）與後綴（suffix），但移除後 `nums` 必須**非空**。

你要求出 `nums` 的 **x 值**：也就是有多少種操作方式，能讓剩下元素的**乘積**除以 `k` 後*餘數*為 `x`。

回傳一個長度為 `k` 的陣列 `result`，其中 `result[x]` 就是 `nums` 對應 `0 <= x <= k - 1` 的 **x 值**。

陣列的**前綴**是指從陣列開頭開始、延伸到其中任一位置的子陣列。

陣列的**後綴**是指從陣列中任一位置開始、一路延伸到結尾的子陣列。

**注意**：這次操作所選的前綴與後綴都可以是**空的**。

 

**範例 1：**

**輸入：** nums = [1,2,3,4,5], k = 3

**輸出：** [9,2,4]

**說明：**

- 當 `x = 0` 時，所有不會把 `nums[2] == 3` 移除掉的不重疊前綴／後綴移除方式都算數。
- 當 `x = 1` 時，可行的操作有：

  - 移除空前綴與後綴 `[2, 3, 4, 5]`，`nums` 變成 `[1]`。
  - 移除前綴 `[1, 2, 3]` 與後綴 `[5]`，`nums` 變成 `[4]`。

- 當 `x = 2` 時，可行的操作有：

  - 移除空前綴與後綴 `[3, 4, 5]`，`nums` 變成 `[1, 2]`。
  - 移除前綴 `[1]` 與後綴 `[3, 4, 5]`，`nums` 變成 `[2]`。
  - 移除前綴 `[1, 2, 3]` 與空後綴，`nums` 變成 `[4, 5]`。
  - 移除前綴 `[1, 2, 3, 4]` 與空後綴，`nums` 變成 `[5]`。

**範例 2：**

**輸入：** nums = [1,2,4,8,16,32], k = 4

**輸出：** [18,1,2,0]

**說明：**

- 當 `x = 0` 時，**不會**得到 `x = 0` 的操作只有：

  - 移除空前綴與後綴 `[4, 8, 16, 32]`，`nums` 變成 `[1, 2]`。
  - 移除空前綴與後綴 `[2, 4, 8, 16, 32]`，`nums` 變成 `[1]`。
  - 移除前綴 `[1]` 與後綴 `[4, 8, 16, 32]`，`nums` 變成 `[2]`。

- 當 `x = 1` 時，唯一可行的操作是：

  - 移除空前綴與後綴 `[2, 4, 8, 16, 32]`，`nums` 變成 `[1]`。

- 當 `x = 2` 時，可行的操作有：

  - 移除空前綴與後綴 `[4, 8, 16, 32]`，`nums` 變成 `[1, 2]`。
  - 移除前綴 `[1]` 與後綴 `[4, 8, 16, 32]`，`nums` 變成 `[2]`。

- 當 `x = 3` 時，沒有任何可行的操作方式。

**範例 3：**

**輸入：** nums = [1,1,2,1,1], k = 2

**輸出：** [9,6]

 

**限制條件：**

- `1 <= nums[i] <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= k <= 5`

## 解題筆記

### 思路
1. **「移除一個前綴和一個後綴，剩下的非空」** ＝ **留下一段連續子陣列**。
所以「有幾種操作方式」就是「有幾個非空連續子陣列」。
  ```
    題目真正在問的是：對每個 `x`，有多少個連續子陣列的乘積 % k == x。
    `x` 只是餘數，也是回傳陣列的索引，所以 `result` 長度才是 `k`。
  ```

2. **按右端點分組做遞推。** 不要想「所有子陣列」，一次只想「以第 i 格結尾的子陣列」。
dp[i] = dp[i-1] 的每個結果 × nums[i]  +  nums[i] 自己單獨一個



### 複雜度

- 時間：O(n × k)。k ≤ 5，等同線性
- 空間：O(k)。用滾動陣列，只留 `cur` 和 `next` 兩個長度 k 的陣列

會這樣做是因為算 `dp[i]` 只用得到 `dp[i-1]`，更早的再也讀不到。
若要事後檢查推導過程，可改成二維 `dp[n][k]`（空間 O(n×k)），答案一樣，除錯時好用。

### 踩到的坑

- **先對元素取餘數再相乘。** 寫成 `(r * nums[i]) % k` 的話，`nums[i]` 最大 1e9，
  在 C++ 會溢位 int。先 `v = nums[i] % k`，`r * v` 最大只有 `4 × 4 = 16`
- **答案會超過 int32。** 子陣列總數可達 `1e5 × (1e5+1) / 2 ≈ 5e9`，超過約 21 億的上限。
  C++ 官方簽名給 `vector<long long>` 就是這個原因；TS 的 number 安全整數到 2^53，沒問題
- **不能原地更新 `cur`。** 必須寫進新的 `next`。一邊讀 `cur[r]` 一邊寫 `cur[新餘數]`，
  同一輪搬過去的會被重複搬第二次
- **兩個 `+=` 不要搞混。** `next[...] += cur[r]` 是在組「這一格」的統計（不同舊餘數可能撞到
  同一個新餘數，所以要累積）；`ans[r] += cur[r]` 才是把這一格併進總帳
- 第一輪 `cur` 全 0，r 迴圈自動空轉，不需要特判 i=0

### 驗證

三個官方範例都過，另外用 `n=1e5` 全 1、`k=1` 測溢位與效能：
答案 5000050000（= 所有子陣列數），耗時 27ms。
